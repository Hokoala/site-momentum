Build WebGL Unity manquant.

Pour générer le build :
1. Ouvrir Unity Editor (le projet momentum-game-v2)
2. Menu : Momentum → Build Mode → Set WEB_BUILD
3. File → Build Settings → WebGL → Build
4. Choisir un dossier de sortie
5. Copier le contenu dans /public/webgl/ via :
   ./scripts/copy-webgl-build.sh <dossier-de-sortie>
